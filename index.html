01 / Mechanism & Motion

轴参数

简易核心初选与判定原则

界面只保留 8 个核心参数。所有未输入项不再读取旧项目预设，而是明确按零处理；固定标准常量只用于公式换算。

唯一使用的输入

负载质量 M、减速比 i、丝杆导程 P、丝杆外径 D、丝杆长度 L、最高速度 V、加速度 a、姿态倾角 θ。

固定标准常量

按原厂 v2 口径：钢制丝杆密度 ρ = 7874 kg/m³；滚珠丝杆效率 η = 0.90；重力加速度 g = 10 m/s²；导轨摩擦 μ = 0.10；峰值安全系数 K = 1 / 0.9 = 1.111；惯量比合格线 λmax = 300%；静止扭矩安全系数 Kstatic = 3；驱动器电流设计系数 Kdrive = 0.7。

内孔 d、工艺力 Fprocess、预紧 Tpreload、附加惯量 Jextra 按零处理；姿态角按原厂代码口径使用 θ/2π。

计算过程

J_bs = π·ρ·L·D⁴ / 32 J_load = (J_bs + M·P²/(2π)²) / i² V_motor = V_table · i / P θ_calc = θ_deg / 2π F = M·g·[sin(θ_calc) + μ·cos(θ_calc)] T_load = F·P / (2π·η·i) α_motor = 2π·a_table·i / P T_peak,motor = [T_load + (J_load/η + J_motor)·α_motor] · K_safety I_req,drive = max(I_motor,max, I_peak) / K_drive λ_motor = J_load / J_motor × 100%

六项通过判据

  • 惯量比：J_load / J_motor × 100% < 300%。
  • 静止扭矩：静止扭矩需求 T_static < 电机额定扭矩 / 3，等价于静止扭矩余量 > 3×。
  • 峰值扭矩：T_peak,motor ≤ 电机最大扭矩。
  • 最高转速：V_table × i / P ≤ 电机最高转速。
  • 峰值电流：I_peak = T_peak / 额定扭矩 × 额定电流，且 I_peak ≤ 电机最大电流。
  • 驱动器电流：I_req = max(电机最大电流, I_peak) / 0.7；驱动器最大电流 ≥ I_req，且驱动器额定电流 ≥ 电机额定电流。

候选池与优先顺序

  • 倾角大于 1°：只选带抱闸电机；水平轴：排除带抱闸电机。
  • 默认排除 K / SK / BK 键槽或特殊轴伸结构。
  • 六项全部通过的型号中，先按额定功率从小到大，再按最大扭矩从小到大排序。
  • 驱动器按“多合一优先、单轴回退”匹配：先找同电压等级多合一驱动的独立轴模块，再回退 SVD / SPD 单轴驱动；额定电流不低于电机额定电流，最大电流不低于“电机最大电流与峰值电流需求中的较大值 ÷ 0.7”。

静态余量、RMS 与驱动器口径

  • 静态扭矩余量：不再只作参考值，已纳入基础校核硬性淘汰；要求额定扭矩 ÷ 静止扭矩需求 > 3。
  • RMS：当前简易版没有有效行程和停留时间，因此不计算 RMS，也不参与淘汰；存在连续运行或高节拍要求时必须另行校核。
  • 驱动器：必须以“电机最大电流与 I_peak 的较大值”为需求，再除以 0.7，预留约 30% 电流余量后参与淘汰；多合一轴模块与单轴驱动器采用同一电流判据。

结果边界

该结果只回答“核心参数下是否能找到最小合格 F 系列电机”。导轨摩擦仅按原厂 v2 固定 μ=0.10 近似；若实际润滑状态、切削力、预紧、联轴器惯量、短行程高节拍、热变形、共振或驱动过载显著偏离该假设，必须另行复核，不能直接用本结果冻结型号。

简易填参说明

只填写机械图纸能够确认的 8 个核心参数。未列出的参数不会参与本次计算。

01

核心 8 参数

这些参数直接决定候选池、转速、惯量和峰值扭矩。

负载质量

工作台、工件、夹具和随动附件总质量。

减速比 i

电机转 i 圈，丝杆转 1 圈时填 i；直连填 1。

丝杆导程 Pb

丝杆每转一圈的直线位移。

丝杆外径 D

按丝杆外径，不是轴承或螺母外径。

丝杆总长度 L

参与丝杆自身惯量计算。

最高速度

设备指令的床台最高速度，不是电机额定转速。

加速度

以 G 为单位；按原厂 v2 口径，1 G = 10 m/s²。

姿态倾角 θ

水平为 0°，重力轴为 90°，中间值按倾斜轴处理。

!

输入项与内置判据分开

内孔、有效行程、工艺力、预紧、附加惯量、停留时间、RMS 和增强校核不再作为输入项读取；导轨摩擦按原厂 v2 固定 μ=0.10。静止扭矩余量和驱动器 30% 电流余量保留为基础校核淘汰判据。

计算采用原厂 v2 口径：g=10、μ=0.10、θ_calc=θ/2π。静止扭矩按“额定扭矩 / 静止需求 > 3”淘汰；驱动器按“需求电流 / 0.7”预留约 30% 后淘汰。该工具仍只适合核心参数初选，有具体切削、预紧或连续运行要求时必须另行复核。
